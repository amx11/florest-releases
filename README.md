# Forest Platform — instaladores

Centro de comando para proteção florestal: detecção de fogo e fumaça por câmera,
triagem, despacho, frota, sensores e clima num só mapa.

## Instalar
Baixe o **Forest Platform Setup** da [última versão](https://github.com/amx11/florest-releases/releases/latest)
e execute. O aplicativo se atualiza sozinho a partir daqui.

> O Windows pode avisar "editor desconhecido" (o instalador não é assinado).
> Clique em **Mais informações → Executar assim mesmo**.

## Suporte
Problemas e sugestões: [abrir um chamado](https://github.com/amx11/florest-releases/issues).

## Uso responsável
O Forest Platform detecta, prioriza e alerta automaticamente. A ordem de combate,
despacho e despejo aéreo é sempre de quem comanda a operação.
